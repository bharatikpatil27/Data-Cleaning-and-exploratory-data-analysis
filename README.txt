PROJECT: TITANIC DATASET - DATA CLEANING AND EDA

OBJECTIVE:
To clean and analyze the Titanic dataset and identify
patterns and relationships between passenger variables.

TOOLS USED:
Python, Pandas, NumPy, Matplotlib, Seaborn, VS Code.

TASKS PERFORMED:
1. Loaded and explored the Titanic dataset.
2. Identified and handled missing values.
3. Removed duplicate records.
4. Analyzed survival rates by gender.
5. Explored survival rates by passenger class.
6. Studied age and fare distributions.
7. Generated correlation heatmap and charts.
8. Saved the cleaned dataset and EDA report.

CONCLUSION:
The analysis explored relationships between passenger
characteristics and survival outcomes in the Titanic dataset.
